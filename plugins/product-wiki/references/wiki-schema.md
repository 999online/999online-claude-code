## Layers

1. `raw/` — immutable sources (stakeholder requests, exports, transcripts, analyst briefs). Never modify after landing.
2. Everything else — generated. Plugin owns it.
3. This file — schema. Update only when conventions change.

## Hard boundary

Plugin writes **only** under `wiki_root`. `project_root` is read-only input, always. No code edits, ever. No auto-commit.

## Conventions

- Slugs lowercase-kebab, stable once written.
- Dates ISO `YYYY-MM-DD`.
- Cross-references use Obsidian `[[wikilinks]]`: `[[features/bulk-export]]`.
- Log line format — one per operation, greppable with `grep "^## \[" log.md | tail -5`:
  `## [YYYY-MM-DD] <intake|bootstrap|deps|sequence|improve|lint|ask|report> | <subject>`

## Frontmatter contract

Every generated page carries frontmatter. Feature pages:

```yaml
---
type: feature
slug: <kebab>
status: proposed | accepted | in-progress | shipped | parked | dropped
priority: p0 | p1 | p2 | p3
owner: <name | unassigned>
epic: <slug | none>
depends_on: [<slug>, <slug>]
blocks: [<slug>]
sources: [raw/<file>, <TICKET-KEY>, systems/<slug>]
created: <YYYY-MM-DD>
last_updated: <YYYY-MM-DD>
last_updated_by: product-wiki
---
```

Other page types: same block minus `priority`/`depends_on`/`blocks`/`epic`, with `type` set to
`epic` / `system` / `persona` / `decision`.

`depends_on` is machine-parsed. Keep it a flat inline list of slugs — no nesting, no prose.

## Hand-edit guard

`last_updated_by` missing or not `product-wiki` → a human edited that page. **Append, never rewrite.**
Add new material under a new heading; leave existing prose alone.

## Conflict handling

New input contradicts an existing page → do not silently overwrite. Append:

> Note (<YYYY-MM-DD>): per [[<source-page>]], <the new statement>. Supersedes the claim above.

Then flag it in the next `product-wiki-lint` run.


## Length budgets — hard caps

| Page | Cap |
|---|---|
| Feature | 400 words |
| Epic / system / persona | 250 words |
| Decision | 200 words |
| `index.md` entry | 1 line |
| `log.md` entry | 1 line |

Over budget → cut, don't append. Drop empty sections. No watermarks, no "generated by" lines, no
emoji, no signatures.
